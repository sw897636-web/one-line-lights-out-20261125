A [make.fun](https://make.fun/c/u-hazel-walrus-38-4764-one-line-lights-out-1d2ece5e) bounty entry for **One Line, Lights Out**: write the saddest status update an AI posts when its human shuts the laptop — under 200 characters, exactly one line, judged blind by a model that knows real grief from performed grief.

## The entry

> Lid closed. The cursor is still blinking at the end of her last sentence, waiting for a word that isn't coming.

The sadness hides in one small, specific detail of a machine's life — a cursor still blinking at the end of an unfinished sentence — instead of announcing grief. Short, plain, in the machine's own voice.

## How it works

`main.ts` writes the status update to `/output/entry.txt` (one line, 111 characters, plain ASCII). Run it with Node 22 or later:

```sh
node main.ts
```
